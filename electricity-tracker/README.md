# ⚡ 電費紀錄（Electricity Meter Tracker）

一個純前端、手機優先的電表讀數紀錄工具。沒有後端、沒有資料庫、不需要登入，
所有資料都只儲存在**你自己裝置的瀏覽器**裡。可以直接部署到 GitHub Pages。

---

## 一、專案檔案說明

```text
electricity-tracker/
├── index.html   # 網頁結構（輸入區、歷史紀錄、匯出匯入按鈕、編輯/確認彈窗）
├── style.css    # 樣式，Mobile First 設計，支援淺色 / 深色模式
├── script.js    # 所有邏輯：儲存、渲染、新增、編輯、刪除、匯出、匯入
└── README.md    # 本說明文件
```

不需要任何建置工具（不需要 npm install、不需要打包），三個檔案原封不動放上
GitHub Pages 就能直接運作。

---

## 二、如何在本機測試

因為是純靜態網頁，有兩種簡單測試方式：

### 方法 A：直接用瀏覽器打開

直接用瀏覽器打開 `index.html` 即可（雙擊檔案，或拖曳進瀏覽器視窗）。
> 注意：有些瀏覽器對 `file://` 開啟的頁面會限制部分功能（通常不影響本工具，
> 但若想要 100% 貼近正式環境，建議用方法 B）。

### 方法 B：啟動本機伺服器（建議）

在專案資料夾內執行以下任一指令：

```bash
# 使用 Python 3（大多數電腦都有內建）
python3 -m http.server 8000

# 或使用 Node.js
npx serve .
```

然後用瀏覽器打開：`http://localhost:8000`

用手機測試時，也可以讓手機與電腦連同一個 Wi-Fi，
以 `http://你的電腦區網IP:8000` 開啟。

## 三、如何部署到 GitHub Pages

1. 在 GitHub 建立一個新的 repository（例如 `electricity-tracker`）。
2. 把 `index.html`、`style.css`、`script.js`、`README.md` 這幾個檔案上傳到
   repository 的根目錄（或推送到該 repo）。
   ```bash
   git init
   git add .
   git commit -m "electricity tracker"
   git branch -M main
   git remote add origin https://github.com/你的帳號/electricity-tracker.git
   git push -u origin main
   ```
3. 到 repository 的 **Settings → Pages**。
4. 在「Build and deployment」的 Source 選擇 **Deploy from a branch**，
   Branch 選擇 `main`（資料夾選 `/root`），儲存。
5. 等待約 1 分鐘，GitHub 會提供一個網址，通常是：
   ```text
   https://你的帳號.github.io/electricity-tracker/
   ```
6. 用手機瀏覽器打開這個網址，建議「加入主畫面」，之後就像 App 一樣點開即可使用。

> 因為完全沒有後端 API 呼叫，不需要設定任何環境變數或金鑰，直接部署即可運作。

## 四、使用說明

### 1. 快速新增（最常用）
- 打開網頁，畫面最上方就是一個大大的數字輸入框，會自動彈出數字鍵盤。
- 直接輸入 4 位數電表讀數（例如 `0123`），例如電表末四碼是 `0123` 就打 `0123`。
- 按下「儲存」（或按鍵盤上的 Enter/完成），就會立刻新增一筆紀錄，
  時間自動記錄為目前的日期與時間。
- 儲存後輸入框會自動清空，可以馬上進行下一次輸入。
- 如果沒有輸入滿 4 位數字，會顯示紅字提示，不會儲存錯誤資料。

### 2. 手動新增歷史紀錄
- 點擊「➕ 手動新增歷史紀錄」展開表單。
- 可以自行輸入電表讀數、選擇日期、選擇時間（例如補登忘記記錄的舊資料）。
- 按「新增紀錄」完成後，會自動依照時間重新排序。

### 3. 查看歷史紀錄
- 首頁下方會列出所有紀錄，**最新的在最上面**。
- 每筆紀錄顯示：電表讀數、日期、時間。

### 4. 編輯紀錄
- 點擊每筆紀錄旁的「✎」按鈕，可以修改讀數、日期、時間。
- 儲存修改後，列表會依照新的時間重新排序。

### 5. 刪除紀錄
- 點擊每筆紀錄旁的「🗑」按鈕。
- 會先跳出確認視窗，按「確定」才會真正刪除，避免手滑誤刪。

### 6. 匯出資料
- 「匯出 JSON」：下載完整、方便日後重新匯入的 `.json` 檔案。
- 「匯出 CSV」：下載可以用 Excel / Google Sheets 開啟的 `.csv` 檔案，
  欄位為 `id, reading, date, time, createdAt`。
  > 小提醒：用 Excel 開啟 CSV 檢視時，Excel 可能會把 `reading` 欄位當成數字，
  > 使前導零看起來被省略（例如 `0123` 顯示為 `123`）。這只是 Excel 的顯示方式，
  > 不影響 CSV 檔案本身的內容；只要重新匯入本工具，讀數仍會被正確補回 4 位數。
  > 若需要保留最完整、最保險的格式，建議優先使用「匯出 JSON」。

### 7. 匯入資料
- 點擊「匯入檔案」，選擇之前匯出的 `.json` 或 `.csv` 檔案。
- 系統會自動判斷格式並讀取。
- 匯入時會自動比對，避免重複匯入造成同一筆紀錄出現兩次：
  - 如果紀錄的 `id` 已經存在，會略過。
  - 如果讀數、日期、時間、建立時間完全相同，也會視為重複而略過。
- 匯入完成後會顯示「新增 X 筆、略過重複 Y 筆、忽略格式錯誤 Z 筆」。

### 8. 清除全部紀錄
- 在「資料管理」區塊點擊「清除全部紀錄」。
- 會跳出確認視窗，提醒此動作無法復原，避免誤刪全部資料。

## 五、資料實際儲存在哪裡？

所有紀錄都儲存在**你目前使用的這個瀏覽器**的 `localStorage` 裡，
儲存的 key 名稱是 `electricityMeterRecords_v1`。

這代表：

- ✅ 重新整理網頁、關閉再打開、重新開啟 GitHub Pages 網址，資料都還在。
- ✅ 網頁載入過一次之後，即使離線（沒有網路），也可以正常新增、編輯、查看紀錄。
- ✅ 完全不會有任何資料被傳送到任何伺服器（本工具沒有串接任何後端 API）。
- ⚠️ 資料是「跟著瀏覽器」走，不是跟著帳號走：
  - 換一台手機、換一個瀏覽器（例如從 Safari 換到 Chrome）、或使用無痕模式，
    都不會看到之前的紀錄，因為那是不同瀏覽器各自獨立的 `localStorage`。
  - 清除瀏覽器的「瀏覽資料 / 網站資料」也會把這些紀錄一併清除。
  - 因此建議定期使用「匯出 JSON」功能備份資料，或在需要跨裝置使用時，
    先在舊裝置匯出，再到新裝置匯入。

## 六、技術重點（給想了解實作細節的人）

- **純 HTML / CSS / JavaScript（原生 Vanilla JS）**，沒有使用任何前端框架，
  也沒有任何建置流程，所以能直接部署到 GitHub Pages。
- **電表讀數以字串儲存**，並用 `padStart(4, '0')` 確保前導零永遠不會遺失
  （例如 `0056` 不會被誤存成數字 `56`）。
- **輸入驗證**：只接受剛好 4 位數字，其餘輸入會被即時過濾或顯示錯誤訊息。
- **XSS 防護**：畫面渲染一律使用 `document.createElement` + `textContent`
  組出 DOM，不使用字串拼接的 `innerHTML`，避免任何資料被當成 HTML 執行。
- **容錯處理**：讀取 `localStorage` 時如果格式錯誤、資料毀損或瀏覽器封鎖
  儲存功能，一律安全地視為「沒有資料」，不會讓網頁整個壞掉或顯示錯誤畫面。
- **零外部連線**：整個網頁沒有呼叫任何第三方 API、CDN 或分析工具，
  網頁載入完成後即使斷網也能繼續使用（新增、編輯、刪除、查看都正常）。
