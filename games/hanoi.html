河內塔Tower of Hanoi・用遞迴解決的經典問題

慢快

程式碼


                    

                        
① 把上面 n−1 個盤子先搬到「輔助柱」，讓最大的露出來

                        
② 把最大的那個盤子搬到「目標柱」

                        
③ 再把那 n−1 個盤子從輔助柱搬到目標柱，疊在它上面

                    

                

                

                    
呼叫堆疊

                    
最上面是正在執行的那一層；虛線框起來的盤子，就是這一層要負責搬的 n 個。

                    

                

            

        


        

            

                
規則

                
    
                    
  1. 把所有盤子從 A 柱搬到 C 柱。
    2. 
                    
  2. 一次只能搬一個盤子，而且只能拿每根柱子最上面那個。
    3. 
                    
  3. 大盤子不能放在小盤子上面。
    4. 
                

                
玩法：先點要拿起盤子的柱子，再點要放下的柱子；再點一次同一根柱子可以取消。電腦也可以用鍵盤 1、2、3。

            

            

                
為什麼最少要 2ⁿ − 1 步？

                
想把最大的盤子搬走，上面的 n−1 個一定要先全部移開，而且只能疊在另一根柱子上；最大的搬過去之後，那 n−1 個又得全部搬回來疊在它上面。所以：

                
T(n) = T(n−1) + 1 + T(n−1) = 2·T(n−1) + 1
T(0) = 0　⇒　T(n) = 2ⁿ − 1

                
3 個盤子 7 步、5 個 31 步、7 個要 127 步。盤子每多一個，步數就翻倍再加一。
